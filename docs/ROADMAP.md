# Roadmap

## Current Status (v1.7)
- ✅ Interactive map booking + polylines
- ✅ Digital wallet + payments (UPI/Card)
- ✅ User/Admin dashboards
- ✅ Realtime SSE updates
- ✅ Auth + vehicles mgmt
- ✅ Analytics/Charts
- ✅ Electron desktop app
- ✅ AI Chatbot (Ollama)

## Short-term (v1.8 - Q4 2024)
- 🔄 Full payment gateway integration (Razorpay/Stripe)
- 🔄 Migrate all localStorage → Backend/DB
- 🔄 User notifications (email/Push)
- 🔄 Booking reminders + auto-release
- 🔄 PDF receipts/export improvements

## Medium-term (v2.0 - Q1 2025)
- 🌐 Mobile app (React Native/Capacitor)
- 📱 PWA install + offline mode
- 🔌 IoT hardware integration (ultrasonic sensors)
- 👥 Multi-parking lot support
- 📊 Advanced analytics (ML occupancy prediction)

## Long-term (v3.0+)
- ☁️ Cloud scale (PostgreSQL/AWS)
- 🚀 Multi-tenant (multiple parking owners)
- 🤖 Full AI (voice booking, route optimization)
- 🔒 Enterprise security (OAuth/2FA)
